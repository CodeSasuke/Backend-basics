# Exercise Levels: Operating Systems And Resources

## Level 1: Follow
Run the worker with a valid file, a missing file, and a malformed line. Record exit behavior.

## Level 2: Modify
Add a new job type and ensure files are closed after success and failure.

## Level 3: Build
Implement the resource-safe worker in `code/exercise.py` with cleanup and meaningful exit codes.

## Level 4: Mastery
Design bounded resource usage for a worker under unlimited input. Explain ownership, interruption, backpressure, and recovery.
