# Exercise Levels: Processes And State

## Level 1: Follow
Run the starter and trace balance, command, output, and next state for five commands.

## Level 2: Modify
Add `reset` and reject invalid amounts without changing the balance.

## Level 3: Build
Implement the ledger in `code/exercise.py` and add tests for every valid and invalid transition.

## Level 4: Mastery
Design a multi-account ledger. State invariants, explain restart behavior, and prove that invalid commands cannot corrupt state.

## Completion Evidence
Record predictions in [experiment.md](experiment.md), answers in [answers.md](answers.md), and update [PROGRESS.md](../../PROGRESS.md).
