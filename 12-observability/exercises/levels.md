# Exercise Levels: Observability

## Level 1: Follow
Read the structured events emitted for one request.

## Level 2: Modify
Add an error event and a correlation field without logging sensitive data.

## Level 3: Build
Implement request timing and telemetry in `code/exercise.py`.

## Level 4: Mastery
Create a diagnosis plan using logs, metrics, and traces for latency, errors, saturation, and dependency failure.
