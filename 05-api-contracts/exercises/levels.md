# Exercise Levels: API Contracts

## Level 1: Follow
Validate example payloads and classify success, client error, and server error.

## Level 2: Modify
Add pagination or a field while preserving the existing client contract.

## Level 3: Build
Write and implement the complete notes contract in `code/exercise.py`.

## Level 4: Mastery
Design a versioning and idempotency strategy for a public API used by independent clients.
