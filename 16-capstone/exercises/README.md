# Capstone Exercises And Tasks

[Previous: Deployment And Scaling](../../15-deployment-scaling/exercises/README.md) | [Theory](../theory/README.md) | [Notes](../theory/notes.md) | [Roadmap](../../ROADMAP.md) | [Build log](experiment.md) | [Review](answers.md) | [Starter code](../code/main.py)

Complete the platform in vertical slices. Each slice must include a contract, code, tests, and evidence.

1. Create and authenticate users.
2. Add private notes with ownership authorization.
3. Add persistence, migrations, search, and pagination.
4. Add an idempotent background report job.
5. Add logs, metrics, request IDs, health checks, and a runbook.
6. Add CI, deployment assumptions, rollback, backups, and capacity estimates.

## Required Artifacts

API contract, domain invariants, architecture diagram, threat model, schema and migrations, test strategy, failure table, operations runbook, scaling plan, and retrospective.

## Final Exit Check

Explain the entire request lifecycle and the behavior of the system when the client retries after a timeout.
