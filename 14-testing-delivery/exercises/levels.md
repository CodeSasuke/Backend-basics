# Exercise Levels: Testing And Delivery

## Level 1: Follow
Write a test for the starter's normal behavior and one invalid input.

## Level 2: Modify
Break the implementation and observe which test detects the regression.

## Level 3: Build
Create a focused test suite and repeatable check for `code/exercise.py`.

## Level 4: Mastery
Design a test pyramid, CI gate, migration check, rollback strategy, and clean-checkout workflow.
