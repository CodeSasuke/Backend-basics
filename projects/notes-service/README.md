# Notes Service Project

This is the shared project thread for the roadmap. Build it gradually; do not jump directly to a framework.

## Milestones

1. In-memory domain rules
2. File and SQLite persistence
3. HTTP API contract
4. Layered application structure
5. Transactions and concurrent updates
6. Background report jobs
7. Timeouts, retries, and idempotency
8. Authentication and authorization
9. Observability and operations
10. Deployment and scaling design

## Project Rules

- Add a test with each behavior.
- Record invariants before implementation.
- Keep the API contract separate from storage.
- Document every deliberate guarantee and limitation.
