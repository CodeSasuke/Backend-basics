# Exercise Levels: Persistence And Data Modeling

## Level 1: Follow
Create the schema, insert valid data, restart, and confirm what persists.

## Level 2: Modify
Add a constraint, violate it, and explain the resulting error.

## Level 3: Build
Implement schema creation and migrations in `code/exercise.py`.

## Level 4: Mastery
Model notes, users, and ownership with invariants, indexes, migration safety, and a backup/restore plan.
