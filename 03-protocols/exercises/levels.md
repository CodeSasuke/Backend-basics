# Exercise Levels: Protocols

## Level 1: Follow
Run valid and invalid messages through the starter parser and classify each failure.

## Level 2: Modify
Add one message field and define how old messages remain compatible.

## Level 3: Build
Implement parsing and encoding in `code/exercise.py`, including malformed bytes and validation errors.

## Level 4: Mastery
Design a versioned protocol with framing, compatibility, limits, and safe behavior for unknown message types.
