# Exercise Levels: Concurrency

## Level 1: Follow
Compare sequential and bounded execution for a small set of jobs.

## Level 2: Modify
Add a failure, cancellation, or worker limit and observe the effect.

## Level 3: Build
Implement the bounded runner in `code/exercise.py`.

## Level 4: Mastery
Choose a concurrency model for CPU and I/O workloads, quantify backpressure, and explain ownership of shared state.
