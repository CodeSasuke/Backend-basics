# Exercise Levels: Networking And HTTP

## Level 1: Follow
Run the health endpoint and inspect method, path, headers, body, and status with `curl`.

## Level 2: Modify
Add one endpoint and return useful JSON errors for unknown paths and invalid input.

## Level 3: Build
Implement the account endpoints in `code/exercise.py` and test them as an external client.

## Level 4: Mastery
Design timeout, retry, idempotency, and graceful-shutdown behavior for a network service.
